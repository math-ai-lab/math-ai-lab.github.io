Can you locate the fault?

A sensor at station C reports how many stops away the fault is. Choose a second sensor to test which station fits both readings.

Could one sensor locate every fault?

Yes. From endpoint A, the five stations are 0, 1, 2, 3 and 4 stops away. Each distance identifies exactly one station. In graph theory, A alone forms a resolving set for this path.
